# IP Geolocation Service

A production-quality FastAPI microservice that provides IP address geolocation information by integrating with [ip-api.com](http://ip-api.com).

---

## Setup

### Prerequisites

- Python 3.11+
- [uv](https://docs.astral.sh/uv/) (`brew install uv` or `pip install uv`)

### Install

```bash
uv sync
```

This creates a `.venv` and installs all runtime and dev dependencies from `uv.lock`.

---

## Running the Service

```bash
uv run uvicorn app.main:app --reload
```

The service will be available at `http://localhost:8000`.

---

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/geolocation/{ip}` | Geolocation for a specific IPv4 address |
| `GET` | `/v1/geolocation/me` | Geolocation for the requesting client's IP |

### Example

```bash
# Specific IP
curl http://localhost:8000/v1/geolocation/8.8.8.8

# Client's own IP
curl http://localhost:8000/v1/geolocation/me
```

### Success Response

```json
{
  "ip": "8.8.8.8",
  "country": "United States",
  "country_code": "US",
  "region": "Virginia",
  "city": "Ashburn",
  "postal_code": "20149",
  "coordinates": {
    "latitude": 39.03,
    "longitude": -77.5
  },
  "timezone": "America/New_York",
  "isp": "Google LLC",
  "organization": "AS15169 Google LLC"
}
```

### Error Response

All errors share a consistent format:

```json
{
  "error": {
    "code": "INVALID_IP_ADDRESS",
    "message": "Geolocation lookup failed: invalid query."
  }
}
```

| Status | Code | When |
|--------|------|------|
| 400 | `INVALID_IP_ADDRESS` | The IP string is not a valid IP address |
| 400 | `RESERVED_IP_ADDRESS` | Private or reserved IP range |
| 404 | `GEOLOCATION_NOT_FOUND` | No geolocation data available |
| 429 | `RATE_LIMIT_EXCEEDED` | Upstream provider rate limit hit |
| 502 | `UPSTREAM_ERROR` | Unexpected upstream provider failure |
| 504 | `UPSTREAM_TIMEOUT` | Upstream provider did not respond in time |

## Configuration

All settings can be overridden via environment variables (prefix `APP_`) or a `.env` file:

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_IP_API_BASE_URL` | `http://ip-api.com/json` | Base URL for ip-api.com |
| `APP_REQUEST_TIMEOUT` | `10.0` | HTTP timeout in seconds |
